# LifeMemo

LifeMemo is a web application developed as part of the *Rituals* project. It is designed to help parents connect with their young children through meaningful everyday interactions.

With activity prompts, visual communication tools, and a digital scrapbook for capturing memories and milestones, LifeMemo helps families reconnect, share experiences, and reflect on their day together, even before children can fully express themselves through words.
